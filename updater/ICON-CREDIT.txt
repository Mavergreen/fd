Updater icon: NONE. fd-updater ships the standard macOS application icon by explicit opt-in
(build_updater.sh --generic-icon), so no artwork is embedded.

Deliberate: fd's logo belongs to the fd project, and this product is an unofficial community build
that must not read as official. A stand-in .icns would be exactly the placeholder the icon gate
rejects.

Exit: when an original Mavergreen fd mark exists, add updater/fd.icns and pass it to
build_updater.sh as --icon in build/build-updater.sh, instead of --generic-icon.
